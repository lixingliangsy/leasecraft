# LeaseCraft — Feature pillars

## Core engine
- Plain-English lease clauses for late rent, pets, deposits, and more
- State-aware framing for landlord and tenant sides
- Drop-in ready language as a starting template

## Workflow & output
- Landlords and tenants get readable clause language fast
- Explicitly a template — not a substitute for counsel
- Common situations covered without drafting from zero

## Trust & control
- Template only — not legal advice; review with local counsel
- No fabricated legal-compliance claims
- Demo mode without a live API key
